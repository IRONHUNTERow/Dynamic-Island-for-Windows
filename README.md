# Dynamic Island for Windows

An iPhone-style Dynamic Island at the top of your Windows screen: what's playing (with a stack of players, lyrics and scrubbing), your AI agents' progress (Claude, Antigravity, Gemini), Windows notifications sorted by importance, downloads and progress from other apps, Bluetooth and earbud batteries, timers, calendar countdown, GitHub and Render build status, and more. Optional **Liquid glass** look that bends and frosts what's behind it, like Apple's glass.

## Install

1. Download **Dynamic-Island-Setup-x.y.z.exe** from the [latest release](https://github.com/IRONHUNTERow/Dynamic-Island-for-Windows/releases/latest).
2. Run it. The installer isn't code-signed yet, so Windows may say "Windows protected your PC": click **More info**, then **Run anyway**.
3. The island appears at the top of your screen. Right-click its tray icon for Settings.

## Updates

The island updates itself: it checks for new versions every few hours, downloads them in the background and installs them when it restarts (or right away when you click "Update ready").

## Good to know

- Windows 10 or 11 (64-bit).
- To show other apps' notifications, Windows asks once for permission (Settings > Privacy & security > Notifications).
- While the island is see-through or glass, it hides itself from screenshots and screen sharing (it reads the screen behind it to draw the glass).

This repository holds the installer downloads. The source code is private.
